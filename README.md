# Radman Tahsildoust Portfolio V6.0

Recruiter-focused cybersecurity portfolio for full-time Security Analyst and SOC roles.

## Included in this release

- GPA removed
- Full-time cybersecurity positioning
- Professional SOC experience section
- Four anonymized, expandable security investigation case studies
- Refined technical skills and projects
- Mobile-responsive layout and reduced-motion accessibility support
- SEO title, description, canonical URL, Open Graph and Twitter metadata
- Schema.org structured data
- `robots.txt`, `sitemap.xml`, favicon, and web manifest
- Resume, LinkedIn, GitHub, and email calls to action

## Deploy

Upload every file and the complete `assets` folder to the repository root. GitHub Pages should deploy from the `main` branch and `/ (root)` folder.

## After deployment

1. Verify the live site at `https://radmantt.github.io/portfolio/`.
2. Add the live URL to LinkedIn, GitHub profile, and the resume.
3. Add the site to Google Search Console using the URL-prefix method.
4. Submit `https://radmantt.github.io/portfolio/sitemap.xml`.
5. Request indexing for the homepage.

A custom domain can be connected later without changing the site design.
